# Scrubbit — Downloads

Scrubbit is a privacy layer between your files and AI. It runs on your computer. Your original files stay on your computer.

## Which file do I download?

| Your computer | You want to | Use this file |
|---|---|---|
| Mac with Apple Silicon (M1 or newer) | Install Scrubbit | `Scrubbit-<version>-arm64.dmg` |
| Mac with Apple Silicon | Update Scrubbit | Nothing — the app updates itself (see below) |
| Windows 10 or 11 | Install Scrubbit | `Scrubbit-Setup-<version>.exe` |
| Windows 10 or 11 | Update Scrubbit | Nothing — the app updates itself (see below) |

Every other file on the release page (`.zip`, `.blockmap`, `.yml`) serves the app's built-in updater. You do not need to download them.

## Install on Mac

1. Requirements: a Mac with Apple Silicon (M1 or newer) and macOS 13 or newer. Intel Macs are not supported.
2. Download `Scrubbit-<version>-arm64.dmg` from the [latest release](https://github.com/ruth989/scrubbit-releases/releases/latest).
3. Open the downloaded file. Drag Scrubbit into the Applications folder.
4. Open Scrubbit from Applications. The app is signed and notarized by Apple, so it opens without a security warning.

## Install on Windows

1. Requirements: Windows 10 or 11, 64-bit.
2. Download `Scrubbit-Setup-<version>.exe` from the [latest release](https://github.com/ruth989/scrubbit-releases/releases/latest).
3. Run the installer. If Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**.

## Update — both platforms

1. Scrubbit checks for a new version when it starts.
2. When a new version exists, the app offers it. Accept, and the app downloads, installs, and restarts itself.
3. Manual alternative: download the installer for the new version (the `.dmg` on Mac, the `Setup .exe` on Windows) and install it over the old one.
4. Your projects, glossaries, and settings are stored outside the app. They survive every update and reinstall.
